## 👨‍💻 Hakkımda

Laravel konusunda uzmanlaşmış, backend odaklı bir yazılım geliştiricisiyim.  
PHP/Laravel ile ölçeklenebilir web uygulamaları, REST API'ler, yönetim panelleri ve üçüncü taraf servis entegrasyonları geliştiriyorum.

Ayrıca Java ve Spring Boot kullanarak katmanlı mimariye sahip backend servisleri üzerinde çalışıyorum. Veritabanı optimizasyonu, raporlama sistemleri, iş süreçlerinin otomasyonu ve sürdürülebilir kod yapıları özellikle ilgilendiğim alanlar arasında.

- 🔭 Laravel ve Spring Boot tabanlı backend projeleri geliştiriyorum
- ⚡ REST API, raporlama ve veritabanı optimizasyonu üzerine çalışıyorum
- 🤖 Python ile otomasyon ve veri işleme araçları geliştiriyorum
- 🌱 Docker ve CI/CD süreçlerindeki yetkinliğimi geliştiriyorum
- 📍 Gaziantep, Türkiye
